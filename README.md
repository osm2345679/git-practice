# git-practice

Open Source Software Lab 7: a small repository for practicing Git and GitHub.

## Purpose

Practice staging files, recording commits, checking history, and pushing a
local repository to GitHub.

## Files

| File | Description |
| --- | --- |
| `README.md` | Repository introduction and usage |
| `.gitignore` | Patterns for secrets and generated files |
| `hello.py` | A small Python greeting program |
| `git-commands.md` | Git command reference |
| `learning-notes.md` | Git concepts and submission checklist |

## Run the example

With Python 3 installed:

```sh
python hello.py
```

Expected output:

```text
Hello, Git!
Track changes locally, then share them on GitHub.
```

## Inspect the repository

```sh
git status
git log --oneline
git ls-files
```
